# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview
Successfully completed the onboarding challenge as a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, setting up the Linux environment, exploring system properties, and establishing a professional GitHub portfolio.

## Objectives
* Access and navigate a cloud-based Linux environment using KillerCoda.
* Gather basic system information and manage files via terminal.
* Create and maintain a professional version-controlled GitHub repository.
* Document technical work using Markdown.

## Activities Performed
1. Provisioned an Ubuntu 24.04 Linux environment on KillerCoda.
2. Created a dedicated user account (`crabanillo`) with `sudo` privileges and a home directory.
3. Gathered and documented system information (`system-information.md`).
4. Built a structured workspace folder tree and wrote an `about-me.md` profile.
5. Initialized and structured the `CCM101-crabanillo` GitHub repository.

## Linux Commands Used
* `useradd`, `passwd`, `usermod`, `su` — User creation and management.
* `uname`, `lsb_release`, `lscpu`, `free`, `df` — System and hardware investigation.
* `mkdir`, `cat`, `ls` — Directory structuring and file creation.

## Skills Learned
* Managing users and permissions in a Linux environment.
* Querying core hardware and OS performance diagnostics via the command line.
* Structuring professional developer documentation in Markdown format.
* Setting up cloud-ready portfolio repositories using Git and GitHub.
