\# Checkpoint 2 - Microsoft Azure Research



\## Brief Overview

Microsoft Azure is an ever-expanding set of cloud services that helps organizations build, manage, and deploy applications across a massive global network.



\## Global Infrastructure

Azure features a vast network of global regions paired for high availability and disaster recovery resilience.



\## Cloud Management Console

The Azure Portal provides a unified web console for provisioning resources, monitoring health metrics, and configuring Role-Based Access Control (RBAC).



\## Four (4) Core Services

1\. Azure Virtual Machines

2\. Azure Blob Storage

3\. Azure SQL Database

4\. Azure Active Directory (Microsoft Entra ID)



\## Three (3) Advantages

1\. Seamless hybrid cloud integration with on-premises infrastructure.

2\. Licensing synergy for existing Microsoft 365 and Windows Server users.

3\. Native integration with Visual Studio and enterprise developer tools.



\## Typical Enterprise Use Cases

\* Hybrid cloud environments combining local datacenters with cloud capacity.

\* Internal corporate line-of-business applications.

\* Identity-driven enterprise security governance.
