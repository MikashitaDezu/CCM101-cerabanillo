## Comparison Questions

**1. Which cloud provider offers the broadest range of services?**

<p align="justify">
AWS offers the broadest range of services, with a catalog that covers nearly every use case, from compute and storage to AI and IoT. AWS markets itself as the most complete cloud platform on the market, and its six-year head start over Azure and GCP is a big part of why: more time in the market meant more time to build out niche services competitors hadn't gotten to yet.
</p>

**2. Which provider best integrates with Microsoft technologies?**

<p align="justify">
Azure, and it isn't close. Since Microsoft builds both, Azure connects natively with Windows Server, Active Directory, Microsoft 365, and .NET applications. It also lets companies sync their existing on-premises Active Directory with Microsoft Entra ID in the cloud, so an organization's identity setup doesn't have to be rebuilt from scratch.
</p>

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

<p align="justify">
Google Cloud Platform, in both areas. GCP created Kubernetes and still leads its development, which is why GKE is generally considered the most mature managed Kubernetes service of the three. On the AI side, GCP's Vertex AI and TensorFlow are heavily used for data-driven and AI-heavy workloads, which tracks given that Google's own products run on this same AI research.
</p>

**4. Which cloud platform would you personally choose and why?**

<p align="justify">
Google Cloud Platform. AI is everywhere now, even e-commerce sites and everyday apps lean on it for product recommendations, chatbots, and fraud detection, and GCP's tooling through Vertex AI and TensorFlow makes it the strongest fit for that kind of work. It also created Kubernetes, so it's a natural choice for running modern, containerized apps. And it runs on the same network infrastructure that already handles Google Search and YouTube at scale, which is a pretty strong track record to build on.
</p>
