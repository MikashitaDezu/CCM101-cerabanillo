\# Checkpoint 2 - Amazon Web Services (AWS) Research



\## Brief Overview

Amazon Web Services (AWS) is the world's most comprehensive and broadly adopted cloud platform, offering over 200 fully featured services from data centers globally.



\## Global Infrastructure

AWS infrastructure is organized into Regions and Availability Zones, providing isolated, fault-tolerant locations worldwide.



\## Cloud Management Console

The AWS Management Console is a web-based user interface that lets administrators manage services, monitor resource metrics, and configure Identity and Access Management (IAM).



\## Four (4) Core Services

1\. Amazon Elastic Compute Cloud (EC2)

2\. Amazon Simple Storage Service (S3)

3\. Amazon Relational Database Service (RDS)

4\. Amazon Virtual Private Cloud (VPC)



\## Three (3) Advantages

1\. Extensive service ecosystem and active community.

2\. Broad global reach and infrastructure maturity.

3\. Advanced enterprise security and compliance tools.



\## Typical Enterprise Use Cases

\* Highly scalable e-commerce and mobile applications.

\* Big data analytics and data lakes.

\* Enterprise backup and disaster recovery.
