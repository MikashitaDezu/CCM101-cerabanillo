# Amazon Web Services (AWS)

</div>

## Brief Overview

<p align="justify">
Amazon Web Services (AWS) is Amazon's cloud computing platform, launched commercially in 2006. It offers more than 200 services covering compute, storage, databases, networking, and artificial intelligence. AWS was the first major public cloud provider, and that head start shows in its customer base, which now runs from small startups to government agencies and large enterprises.
</p>

## Global Infrastructure

<p align="justify">
AWS splits its physical infrastructure into <b>Regions</b>, isolated geographic areas around the world. Each Region contains several independent <b>Availability Zones (AZs)</b>, each with its own power, cooling, and networking, so a failure in one zone does not take down the others. AWS also runs a network of <b>Edge Locations</b> through Amazon CloudFront that cache content closer to users to cut latency. The result is that an application can be built to survive the loss of an entire data center without going down.
</p>

## Cloud Management Console

<p align="justify">
The <b>AWS Management Console</b> is the web interface for provisioning, monitoring, and configuring AWS resources. After signing in, the Console Home dashboard lets you:
</p>

- Search for and launch AWS services
- Check system health notifications and billing metrics
- Launch **AWS CloudShell** for command-line access directly in the browser
- Manage security settings and resource tags

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Resizable virtual server instances, so compute capacity can scale up or down with demand instead of being fixed in advance.

2. **Amazon S3 (Simple Storage Service)** – Object storage for any amount of data, used for websites, mobile apps, backups, and data lakes.

3. **Amazon RDS (Relational Database Service)** – A managed relational database service that handles provisioning, patching, and backups for engines like MySQL, PostgreSQL, and Oracle.

4. **AWS IAM (Identity and Access Management)** – Controls who can access AWS resources, letting administrators set fine-grained permissions, user roles, and multi-factor authentication.

## Three (3) Advantages

1. **Widest Range of Services** – AWS has more purpose-built services than either Azure or GCP, which cuts down on the need for third-party tools to fill gaps.

2. **Largest Global Footprint** – AWS runs the largest network of data center regions of the three platforms, which helps both with performance and with meeting local data residency rules.

3. **Track Record on Security** – AWS has been running this infrastructure since 2006, and that time shows in its compliance certifications and governance tooling.

## Typical Enterprise Use Cases

- Hosting high-traffic web applications, APIs, and mobile app backends
- Big data processing and business intelligence on multi-petabyte data lakes
- Automated cloud backup, archiving, and cross-region disaster recovery
- Machine learning development and inference deployment through Amazon SageMaker
- Large-scale data center migrations and hybrid cloud operations
