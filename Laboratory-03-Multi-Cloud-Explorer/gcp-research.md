\# Checkpoint 2 - Google Cloud Platform (GCP) Research



\## Brief Overview

Google Cloud Platform is a suite of cloud services running on the same infrastructure Google uses internally for products like Search and YouTube.



\## Global Infrastructure

GCP runs on Google's private global fiber-optic network, optimizing throughput and reducing latency.



\## Cloud Management Console

The Google Cloud Console provides a centralized web interface alongside Cloud Shell for executing command-line operations and managing project billing.



\## Four (4) Core Services

1\. Google Compute Engine (GCE)

2\. Google Cloud Storage

3\. Google Kubernetes Engine (GKE)

4\. BigQuery



\## Three (3) Advantages

1\. Industry-leading big data analytics and AI/ML capabilities.

2\. Pioneer and creator of the Kubernetes container ecosystem.

3\. High-performance global private network backbone.



\## Typical Enterprise Use Cases

\* Advanced data warehousing and predictive analytics.

\* Containerized microservices deployments.

\* Global web applications requiring edge caching.
