\# Checkpoint 4 \& 6 - Client Recommendations and Decision Matrix



\## Checkpoint 4: Client Recommendations



\### Client A - Startup Company

\* \*\*Recommended Platform:\*\* Amazon Web Services (AWS)

\* \*\*Justification:\*\* AWS offers a generous free tier, pay-as-you-go pricing, and extensive scalability options that fit a limited startup budget while supporting rapid future growth. 

\* \*\*Services Used:\*\* Amazon EC2, AWS Lambda, Amazon RDS.



\### Client B - University

\* \*\*Recommended Platform:\*\* Microsoft Azure

\* \*\*Justification:\*\* Since the university already relies on Windows Server, Microsoft 365, and Active Directory, Azure provides native compatibility, simplified license management, and smooth directory synchronization.

\* \*\*Services Used:\*\* Azure Virtual Machines, Microsoft Entra ID, Azure Files.



\### Client C - AI Research Company

\* \*\*Recommended Platform:\*\* Google Cloud Platform (GCP)

\* \*\*Justification:\*\* GCP provides superior data processing engines, high-performance computing clusters, and deep machine learning optimization that match intense AI research workloads.

\* \*\*Services Used:\*\* Google Compute Engine with GPUs, Vertex AI, BigQuery.



\### Client D - Global E-Commerce Company

\* \*\*Recommended Platform:\*\* Amazon Web Services (AWS)

\* \*\*Justification:\*\* AWS offers a robust global footprint, low-latency edge locations, and mature auto-scaling features necessary to maintain high availability for worldwide shoppers.

\* \*\*Services Used:\*\* Amazon CloudFront, Amazon EC2 Auto Scaling, Amazon Aurora.
