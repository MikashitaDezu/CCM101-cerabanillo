# Public Cloud Providers Infrastructure Comparison

## Service Comparison Table

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 (Elastic Compute Cloud), AWS Lambda | Azure Virtual Machines, Azure Functions | Google Compute Engine, Cloud Functions |
| **Storage** | Amazon S3 (Simple Storage Service), EBS | Azure Blob Storage, Azure Disk Storage | Google Cloud Storage, Persistent Disk |
| **Networking** | Amazon VPC (Virtual Private Cloud), Route 53 | Azure Virtual Network, Azure DNS | Google Virtual Private Cloud (VPC), Cloud DNS |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Google Cloud IAM |

## Guide Questions & Analysis

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) currently offers the broadest and most mature range of services in the cloud industry. Because AWS entered the cloud market significantly earlier than its competitors, it has had more time to develop, expand, and refine a massive catalog spanning specialized databases, IoT, machine learning, and enterprise migration tools.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
For an organization heavily invested in Microsoft products, Microsoft Azure is the clear recommendation. Azure provides seamless, native integration with enterprise tools like Active Directory (Microsoft Entra ID), Windows Server, Office 365, and SQL Server, making hybrid cloud deployment and license management much smoother.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized as a pioneer and industry leader in Artificial Intelligence, Machine Learning, and container orchestration. Google originally created Kubernetes as an open-source project and built foundational AI frameworks like TensorFlow, giving GCP a distinct edge in data-heavy and containerized workloads.

### 4. What similarities did you observe among the three cloud providers?
All three major cloud providers share a core architectural model built upon the pillars of scalable compute, secure object and block storage, virtual networking isolation (VPC/VNets), and strict identity and access management (IAM). They all operate on a pay-as-you-go consumption model, allowing global businesses to provision resources on demand without maintaining physical on-premise hardware centers.
